## Exact level formulas (as implemented)

| Level | Internal scanner | TradingView ingest |
|---|---|---|
| **Entry** | pullback: `swingExtreme ∓ 0.50 × leg` (limit) · OB: proximal block edge (limit) · retest: `brokenLevel` (limit) · sweep: confirmation close (market) · range: market at outer 12% | `entryCandidate` from the chart, unchanged |
| **Stop** | pullback: `anchorSwing ∓ 0.50×ATR` · OB: `distalEdge ∓ 0.35×ATR` · retest: `level ∓ 1.00×ATR` · sweep: `sweepExtreme ∓ 0.25×ATR` · range: `extreme ∓ 0.50×ATR` | `stopCandidate ∓ 0.25×ATR` |
| **TP1** | pullback: impulse extreme · others: `entry ± 1.5 × risk` · range: mid-range | swing extreme if in `[0.8R, 1.6R]`, else `entry ± 1.0R` |
| **TP2** | pullback: `extreme ± 0.618 × leg` · others: nearest unswept liquidity if `≥1.6–1.8R`, else `entry ± 2.4–2.5 × risk` · range: far 15% band | `tpCandidate` if `≥1.6R`, else app liquidity `≥1.6R`, else `entry ± 2.4R` |
| **R:R** | `(rewardPips − cost) / (riskPips + cost)`, `cost = spread + expected slippage` | same |
